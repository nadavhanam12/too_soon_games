# שיתוף

**סטטוס: החלטה**, למעט רשימת חשבונות הסטודיו (ממתינה לקישורים).

## מה למדנו מ"טיסה נעימה"

עבד: כפתור ווצאפ מרכזי וברור, טקסט שיתוף עם תוצאה ודרגה אישית, כפתור העתק עם אישור "הועתק".
לא נשאר: קבוצת ווצאפ ייעודית וווצאפ פרטי (מובילים לאדם, לא לסטודיו). שיתוף המערכת נכשל בתוך
itch; בדומיין שלנו הוא עובד.

## מבנה בלוק השיתוף (זהה בכל ערכה)

```
[   כפתור מרכזי: אפליקציית ההודעות של הקהל   ]   ← גדול, צבע האפליקציה
[ שתף...  (שיתוף מערכת) ]  [ העתק קישור ]         ← שורה שנייה
```

- **הכפתור המרכזי** פותח את האפליקציה שבה הקהל מתכתב עם חברים, עם הטקסט מוכן.
- **שתף...** פותח את גיליון השיתוף של המערכת (Instagram, Snapchat, Telegram, Messenger, מייל...).
  בדסקטופ בלי Web Share הכפתור מוסתר.
- **העתק קישור** מעתיק את הטקסט המלא. מאשר "הועתק ✓" רק אם באמת הועתק.

## ערכות לפי קהל (`audience`)

| | `il` | `us` |
|---|---|---|
| שפה, כיוון | he, rtl | en, ltr |
| כפתור מרכזי | **שיתוף בווצאפ** `https://wa.me/?text=` | **Text a friend** `sms:?&body=` (iMessage/SMS) |
| שורה שנייה | שתף... / העתק | Share... / Copy link |
| פורמט תוצאה | `0:42 דקות`, מספרים עם פסיקים | `0:42`, מספרים עם פסיקים |

ווצאפ בארה"ב: כ־25-30% מהמבוגרים, בעיקר מהגרים וקשרים בחו"ל. ההודעות האישיות עוברות ב־iMessage
ו־SMS, ואצל צעירים גם Snapchat ו־Instagram DM. לכן בארה"ב הכפתור המרכזי הוא `sms:` (בטלפון פותח
את iMessage או Messages עם הטקסט), ושיתוף המערכת מכסה את השאר. בדסקטופ `sms:` לא עובד, ואז
הכפתור המרכזי הופך ל־"Copy link".

ערכה חדשה (למשל `uk`, `de`) = שורה בטבלה הזו + קובץ ב־`share/presets/`.

## טקסט השיתוף

תבנית ב־`game.json.share.text`, עם משתנים: `{result}` (התוצאה במילים של המשחק), `{rank}`,
`{url}`. עד 200 תווים לפני הקישור. דוגמה (il):
```
חופשה בטוחה ✈️ הצלתי 174 נוסעים ב-{result}. דרגה "{rank}". תנצח אותי? {url}
```

## קישור אתגר

הקישור שמשתפים נושא את התוצאה: `https://<domain>/<gameid>/?c=<score>&n=<nick>&u=<shortUserId>`.
- `title` מזהה את הפרמטרים ומציג באנר: **"דני עשה 0:42. תנצח אותו?"** (אם אין כינוי: "חבר שלך").
- שולח `referral_start {fromUser, theirScore}`. כך יודעים כמה פתיחות הגיעו משיתוף, ושל מי.
- אין דף נחיתה נפרד. הבאנר נבנה בלקוח מהפרמטרים.
- **תצוגה מקדימה אישית (הוחלט 2026-11-14, בתבנית):** Pages Function קטנה (`functions/[game]/index.ts`)
  מזהה בקשה עם `?c=` ומחליפה ב־HTML, בדרך החוצה, את `og:title` ו־`og:description` ל־
  "דני עשה 0:42. תנצח אותו?" + משפט המשחק. התמונה נשארת `og.png` של המשחק (יצירת תמונה אישית
  היא שלב ב'). בקשה בלי פרמטרים מוגשת כקובץ סטטי רגיל, בלי קוד.
  - בלוגיקה: `share` מייצר את הקישור עם `c`, `n`, `u`; `title` קורא אותם; `track('referral_start')`.
  - בבדיקות (bugcheck): בקשה ל־`/<game>/?c=42&n=Dani` מחזירה `og:title` עם "Dani"; בלי פרמטרים
    מחזירה את הכותרת הרגילה; `n` עם HTML נבלע (escape).
  - גבולות: `n` עד 16 תווים, `c` מספר שלם, אחרת מתעלמים ומגישים את הרגיל.

## תצוגה מקדימה (OG)

כל משחק מספק `og.png` 1200x630 ו־`og:title`, `og:description` ב־`game.json`. ה־build מכניס אותם
ל־`index.html`. הבדיקה אחרי פרסום (חוק 23): שולחים את הקישור לעצמנו בווצאפ ורואים כרטיס תקין.

## עקבו אחרינו (בלוק הקהילה)

"רוצים להיות הראשונים לשחק במשחק החדשות והטרנדים הבא?" + כפתור לכל רשת שיש בה חשבון לסטודיו.
הקישורים ב־`GamesTemplate/studio.json` (משותף לכל המשחקים):
```json
{ "name": "Too Soon Games", "instagram": "", "tiktok": "", "x": "", "facebook": "", "youtube": "" }
```
**הבלוק מעוצב ומוצב מהיום** (הוחלט 2026-11-14): במסך הקהילה הוא הבלוק העליון, מתחת לכותרת,
בגובה 110 יחידות: משפט אחד + שורת ארבעה עיגולי אייקונים (Instagram, TikTok, X, Facebook) ברוחב
56 כל אחד, רווח 16, ממורכזים. בפורטל: אותו בלוק בתחתית כל עמוד. הקישורים יוכנסו בהמשך; עד אז
אייקון בלי קישור מוצג חצי־שקוף ולא לחיץ, כדי שהעיצוב והמיקום יהיו סופיים כבר במשחק הראשון.
