# Too Soon Games - תבנית המשחקים

התבנית שממנה נבנה כל משחק חדש. היעד: משחק מאירוע חם ליציאה לאוויר בתוך 10 שעות,
כשכל מה שחוזר על עצמו (מסכים, שיתוף, לידרבורד, אנליטיקה, פרסום) כבר מוכן ומתועד.

## מבנה

```
GamesTemplate/
  common-game-code/   קוד הלקוח המשותף: שלד המשחק, מסכים, שיתוף, אנליטיקה, לידרבורד, user id
  server-and-data/    השרת (Cloudflare Worker), מסד הנתונים (D1), אנליטיקה, גיבויים, פריסה
  other-services/     כלים וסקילים: מחקר אירוע, בדיקת באגים, פריסת שרת, פרסום משחק
  frontend/           אתר הסטודיו: פורטל, עמוד משחק נבחר, עמודי החובה, Pages Functions
  docs/               החוקים, הארכיטקטורה, יומן ההחלטות והמדריכים
```
