# itch.io Theme editor values (works without custom CSS)

Edit game → **Theme** tab:

| Setting              | Value                                                   |
|----------------------|---------------------------------------------------------|
| Background color     | `#0f0f0f`                                               |
| Background image     | none (optional: a 32×32 px PNG with a faint green grid, tiled) |
| Text color           | `#f3ead6`                                               |
| Link color           | `#76b900`                                               |
| Button color         | `#76b900`                                               |
| Button text color    | `#0b0b0b`                                               |
| Font                 | **Rubik** (Custom font → Google Fonts)                  |
| Header text color    | `#76b900`                                               |
| Screenshots          | Sidebar. 4 shots: title screen, a Trump bounce, the "date" moment, the stamped resignation letter |
| Banner (960×200)     | black grid background, the CEO falling past H100 chips, "DROP THE CHIP 📉" in a tilted green marker box |
| Cover image (630×500)| same art, portrait crop, the title box big and centered |

Once itch enables **Custom CSS** for your account (Dashboard → Settings → request it,
one-time approval), paste `itch.css` into the CSS box on the Theme tab.
The values above stay as the fallback while CSS loads or if it is rejected.
