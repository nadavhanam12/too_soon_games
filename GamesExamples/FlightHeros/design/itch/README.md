# חבילת עיצוב לדף itch — חופשה בטוחה

החבילה מקומית בלבד. הדף הציבורי והמשחק לא שונו.

## הגדרות ב־Edit theme

- Background: `#0b1424` (קודם: רקע חיצוני אפור בהיר).
- Background image: `background.png`, חזרה כרקע; ללא מתיחה.
- BG2: `#0f1a2b`, Alpha: 100% (קודם: עמודת תוכן לבנה).
- Text: `#f6f1e6`.
- Headers / Link / Buttons: `#ffb400` (כפתור התמיכה היה אדום).
- Font: Rubik; גודל תיאור 17px אם השדה זמין.
- Header image: `banner.png`. התמונה כוללת את שם המשחק.
- Layout: single column / Screenshots Hidden.
- השאירו את המשחק במידות 360×640 הקיימות.

## תיאור

ב־Edit game הדביקו את תוכן description.html במצב HTML, או העתיקו את הטקסט המוצג בתצוגה המקדימה לעורך העשיר. בדקו כיווניות עברית אחרי שמירה.

## תצוגה מקדימה

preview.html מציג את הנכסים והתיאור סביב המשחק האמיתי. זו הדמיה מקומית, לא העתק מדויק של itch. פרטי הניקוב בבאנר והרקע אינם דורשים Custom CSS. פס הטיסה הנוסף בתצוגה הוא המחשה בלבד; המידע כבר נמצא בבאנר ובתיאור.

אין צורך ב־Custom CSS כדי להוסיף באנר, רקע וצבעים. itch דורש הפעלה מיוחדת לחשבון עבור Custom CSS, ולכן החבילה אינה תלויה בכך.
מקור: https://itch.io/docs/creators/design

לפני פרסום בדקו קריאות הבאנר בטלפון, כיווניות התיאור והניגודיות של כפתור התמיכה. שמירת theme ותיאור ב־itch היא שלב ההוספה לדף הציבורי.
